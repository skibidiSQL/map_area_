# 🗺️ Карта пространства (Space Map)

Веб-приложение для создания и просмотра интерактивных 2D-планов помещений и мероприятий. Проект позволяет организаторам легко рисовать схемы залов, расставлять точки интереса и привязывать 360° панорамы, а посетителям — ориентироваться в пространстве и строить маршруты.

## 🌟 Текущие возможности

### Для посетителей (Режим просмотра)

* **Интерактивная 2D-карта:** Удобный просмотр плана помещений с поддержкой зума и панорамирования.

* **Построение маршрутов:** Поиск кратчайшего пути между двумя Точками (с расчётом расстояния и времени).

* **360° Панорамы:** Виртуальные туры по локации (с использованием `Three.js`) с возможностью перехода между соседними панорамами прямо в 3D-режиме.

* **Офлайн-режим (PWA):** Карта сохраняется на устройстве и доступна даже без интернета (включая скачивание карты в виде единого `.html` файла).

### Для организаторов (Режим редактирования)

* **Редактор плана:** Инструменты для отрисовки залов (▭), коридоров (▬) и расстановки точек (📍).

* **Мультиэтажность:** Создание и управление несколькими этажами в рамках одной карты.

* **Управление панорамами и умная проверка:** Загрузка панорам в облако (Supabase). Система автоматически проверяет качество загружаемого файла (пропорции, разрешение, правильность стыков).

* **Импорт/Экспорт:** Загрузка готовых планов в форматах JPG/PNG или полная выгрузка/загрузка структуры этажа в JSON.

* **Совместный доступ:** Настройка прав доступа по ссылке (только просмотр или редактирование).

## 🛠 Технологии

Проект написан на чистом JavaScript без использования UI-фреймворков для обеспечения максимальной скорости работы на мобильных устройствах.

* **Frontend:** HTML5, CSS3, JavaScript.

* **Векторная графика:** SVG (генерация плана).

* **3D Движок:** [Three.js](https://threejs.org/) (рендер 360° панорам).

* **База данных и облако:** [Supabase](https://supabase.com/) (PostgreSQL + Storage для картинок).

* **Локальное хранилище:** IndexedDB (для работы в офлайн-режиме).

* **Веб-приложение:** Service Workers (кеширование ресурсов).
